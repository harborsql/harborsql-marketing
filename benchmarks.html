Benchmarks

Where HarborSQL is faster, cheaper, and where warehouses still win.

HarborSQL is strongest on concurrent point lookups and compute economics. Full analytical suite benchmarks are included with the current caveats because those numbers matter when choosing the right execution path.

Cost profile

Cheaper per run under the benchmark assumptions.

Using client wall time and a European Databricks SQL Warehouse price of $0.90 per DBU, the 2X-Small warehouse costs about $0.1368 per full ClickBench run. HarborSQL on i3.2xlarge on-demand EC2 costs about $0.0385 to $0.0483 per European run.

That makes on-demand HarborSQL roughly 2.8x to 3.6x cheaper for the measured run. Spot was cheaper again in the point-in-time snapshot, but interruption risk belongs in the deployment decision.

Full suite context

Broad analytical batches are still a warehouse strength today.

On the 43-query ClickBench client-wall-time comparison, Databricks completed the measured run faster overall. HarborSQL exposes the current bottlenecks: regex/string kernels, Parquet filter pushdown behavior, and high-cardinality aggregation in DataFusion.

What to benchmark

Use HarborSQL when the workload benefits from locality and simple serving.

  • Concurrent point lookups and service-style query traffic.
  • Cost-sensitive read paths where EC2 economics beat warehouse DBUs.
  • Local development against real Unity Catalog permissions.
  • Read-only Delta workloads that fit the current result type support matrix.
