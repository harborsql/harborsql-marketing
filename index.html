A FEW IMPORTANT DETAILS

Know the boundaries.

Does HarborSQL replace Databricks?

No. It provides alternative compute for supported SQL workloads. Your Databricks workspace and Unity Catalog remain in place. It does not replace the full platform or managed warehouse operations.

Does my data move?

No data copy is needed for supported reads. HarborSQL reads your existing Delta tables on S3 using temporary table credentials requested through Unity Catalog.

Which clients and SQL features are supported?

HarborSQL supports a focused Databricks SQL connector and JDBC protocol surface. It is not blanket compatibility with all SQL, ODBC, or BI tools. Read the SQL compatibility notes and test your client.

Can I run dbt today?

Not as a verified supported workflow. Write support is in development, targeting existing dbt-databricks projects without model or adapter changes. That target is not a compatibility guarantee.

Does it enforce every Unity Catalog policy?

Table access uses your Databricks identity and Unity Catalog credentials. That does not establish full support for row filters, column masks, views, or every governance feature. Review your policy requirements before moving a workload.

What do I need to operate?

You operate the HarborSQL service and its compute, networking, TLS, monitoring, and upgrades. The software is MIT licensed; infrastructure and operational costs still apply.
