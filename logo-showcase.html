A test direction built around a stylized dot H. The mark uses a compact data-dot grid so the letter stays readable in the site header and favicon.

Six SVG variants

Distinct directions for a database engine that sits beside governed Delta data.

Each variant uses a 100 by 100 viewBox and a restrained geometric vocabulary so the mark can scale from favicon to presentation artwork.

01 / Primary direction

Dot H

A stylized H made from rounded table/data dots. The center bridge is slightly smaller so the mark feels like a dot system instead of a block letter.

Open SVG

02 / SQL prompt

Dock Brackets

Bracket-like docks frame a compact prompt. It leans more developer-tool than infrastructure brand, but stays simple and recognizable.

Open SVG

03 / Unity Catalog

Catalog Mooring

A cove-shaped boundary carries three governed table points. This direction is more catalog-forward while remaining lighter than the previous mark.

Open SVG

04 / Compatibility

Protocol Span

Two endpoints connected by a clean span emphasize Databricks SQL client compatibility and the server's role as an execution bridge.

Open SVG

05 / Security model

Governed Channel

A shield boundary around a narrow H-channel makes the Unity Catalog security model explicit without depending on small decorative nodes.

Open SVG

06 / Result pages

Result Current

Three compact result rows flow through a returning channel. This one pushes closest to DataFusion/Arrow output while staying abstract enough for brand use.
